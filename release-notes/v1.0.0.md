# v1.0.0 — Digital Smarts Challenge

First public release of **WGRALGO Digital Smarts Challenge** — a free, offline Android app for practicing stronger ChatGPT prompts, Google searches, YouTube how-to searches, source checking, and digital safety habits through quick **Bad / Good / Better / Best** scenarios.

## Highlights

- 40+ built-in scenarios across 5 categories
- 5-scenario shuffled rounds
- Only the **Best** option scores
- Instant feedback + "why Best wins" lesson on every answer
- Final rating screen (Digital Master → Restart the Challenge)
- 100% offline — no network permission, no analytics, no trackers
- WGRALGO black + gold premium card UI

## Install

1. Download `DigitalSmartsChallenge-v1.0.0.apk` from the assets below.
2. Verify the checksum with `sha256sum`.
3. Sideload on Android.

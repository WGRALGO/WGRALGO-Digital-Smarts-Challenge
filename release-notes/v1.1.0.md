# Digital Smarts Challenge v1.1.0

## What's new

- **New scenario bank:** 60 scenarios across **AI Chatbots**, **Google**, and **YouTube**, plus a **Mix** mode.
- **10 scenarios per round.** Every answer scores: Best 3, Better 2, Good 1, Bad 0. Review all your answers at the end.
- **Looks like a real app:** black launch screen with the big WGRALGO logo, new launcher icon, solid app bar, and About / Privacy / Credits sheets.
- **Back button works:** closes a sheet, returns to the menu, then asks before exiting.
- Still **100% offline** — no internet permission, no ads, no analytics, no accounts.

## Important: uninstall v1.0.0 first

This release is signed with a new key, so it cannot install over v1.0.0. Uninstall the old app first. The app stores nothing, so nothing is lost.

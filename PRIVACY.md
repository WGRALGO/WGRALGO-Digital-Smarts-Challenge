# Privacy Statement — Digital Smarts Challenge

**Last updated:** 2026-10-01 (v1.1.0)

Digital Smarts Challenge is an offline educational digital-literacy game published by **The Wealth Gap Resolution Algorithm™ Inc. (WGRALGO)**.

## What we collect

**Nothing.**

- **No account required.**
- **No ads.**
- **No analytics.**
- **No trackers.**
- **No data selling.**
- **No cloud upload.**
- **No personal data is collected.**
- **No answers or scores are sent to WGRALGO.**
- The app declares no network permission. It runs fully offline.

## Data stored on your device

- The app does not persist your scores or selections between sessions.
- All scenario content is bundled in the APK at install time.

## Permissions

The app requests **no permissions** — no internet, no location, no contacts, no camera, no microphone, no storage.

## Children's privacy

The app does not collect any data, including from children.

## Changes to this statement

If this statement changes in a future release, the update will appear in this file and in the release notes for that version.
